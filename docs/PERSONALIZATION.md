# 个性化训练

本工具只有一位使用者，因此用使用者本人的声音微调唤醒（KWS）和命令识别（ASR），重点改善播放音乐时的识别。
通用方案的现状见 [EVALUATION.md](EVALUATION.md) 第 8、9 节：安静 0.5 米已接近 100%，放音乐时约 54–77%；
软件 AEC 在当前硬件上无效（ReSpeaker Lite 的板载处理先改变了麦克风信号），而使用者希望保留音箱的 USB 直连。

## 数据

| 用途 | 怎么录 | 说明 |
| --- | --- | --- |
| 训练 | 采集页“个性化训练数据”，安静和播放音乐各录几轮，每轮 60 条 | 标注 `purpose: "train"`；`evaluate` 会跳过这些会话 |
| 数据增强 | 背景录音模式，只放音乐、不说话，换几首歌（含人声） | 把安静的训练录音和真实麦克风里的音乐混合；ReSpeaker 的处理是非线性的，混合只是近似 |
| 评估 | 采集页的命令组 | 训练永远不使用评估会话，只用它们对比微调前后 |
| 误执行回归 | 日常背景录音（可选） | 微调后的模型可能更倾向于把普通话语识别成命令 |

每轮训练提示按采集编号随机生成，可复现：10% 只说唤醒词（两步说法的第一步），15% 不带唤醒词的命令，75% 完整命令；
完整命令中唤醒词前置/后置约各半，约 30% 为两条命令，音量命令约六成带 1–20 的百分比；约 30% 的提示附带语气提示
（快一点、轻一点等），让数据覆盖平时的说话状态。

## 数据集导出

```powershell
python tools/export_dataset.py
```

把 `data/sessions` 下的录音整理成逐条样本，写到 `data/dataset/`（不改动原始会话，重跑会整体重建；新录的会话重跑一次即可纳入）：

| 路径 | 内容 |
| --- | --- |
| `clips/<会话>/<样本>.wav` | 麦克风，16 kHz 单声道 int16 |
| `reference/<会话>/<样本>.wav` | 同一时间段的音箱 loopback，格式相同（按 QPC 时间戳对齐） |
| `manifest.jsonl` | 每条样本一行：split、kind、条件、唤醒词、提示文字、规范化文本、期望动作、电平、是否在放音乐等 |
| `summary.json` | 按 split / kind / 条件统计的条数和时长 |

- 每条命令样本取“提示出现前 0.2 秒”到“按下空格后 0.05 秒”，避开按键声；只导出状态为 ok 的样本（重录前的读错版本不导出）。
- 静默段、背景录音、无标注会话切成 10 秒一段。早期 48 kHz 的麦克风录音会重采样；没有正常结束的录音（WAV 头长度为 0）按文件实际长度读取。
- `speech_s` 是基于能量的语音起止，只在安静时给出，仅供参考：底噪起伏大的片段可能把噪声算进去，训练时应以 VAD 重新确定。
- split 规则：当前唤醒词（小克）的评估会话为 `test`，**不得用于训练**；训练模式会话为 `train`，其中按样本 ID 哈希固定 10% 为 `dev`；
  旧唤醒词（小助手）的评估会话归入 `train`（其中没有“小克”，同时可作唤醒负样本）；无标注会话为 `unlabeled`。

2026-09-25 首次导出：20 个会话、187 条样本（65 MB）：test 70 条 305 秒、train 69 条 323 秒、unlabeled 48 条 426 秒；
还没有训练模式的录音。用现有识别模型解码核对对齐：安静时转写与标注的平均字符重合 94–97%，唯一低于 70% 的一条是
2 米处的真实识别错误；放音乐时 78–92%。

## 模型

- **唤醒**：`sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20`。训练代码见 k2-fsa/icefall#1428，上游提供可微调的
  PyTorch 检查点（`pretrained.pt`，epoch-13-avg-2）。微调后用 icefall 导出流式 ONNX，替换 `kws.*` 的模型路径。
- **识别**：Fun-ASR-Nano-2512 的 CTC 分支（配置里的 `sense_voice` 类型）。FunASR 提供微调流程；微调后需要重新导出为
  sherpa-onnx 可加载的 ONNX，这一步尚待验证。

训练在 WSL2 + CUDA（RTX 4090）中进行，录音留在 E: 盘，通过 `/mnt/e` 访问。安装步骤见
[WSL_TRAINING_SETUP.md](WSL_TRAINING_SETUP.md)。

## 风险

- 只用命令数据微调识别模型，会让它倾向于把任何话语识别成命令。需要混入通用中文语料，并用日常背景录音检查误执行。
- 数据增强的混合音频与真实“边放音乐边说话”并不完全相同，最终以真实录音的评估为准。
